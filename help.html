📘 Evidence Stamp User Guide

A tool to preserve "evidence" needed for bug reports and system investigations in one click.
It continuously records your actions and the browser's background movements like a dashcam.

1. Basic Usage

  1. Open the page where the issue occurs.
  2. Press Ctrl + Shift + E (Cmd+Shift+E on Mac).
  3. The analysis screen will open. Verify the content and save or copy it.
💡 Logs are not reset:
This tool continues recording even if you reload the page or move to another page within the same site.
You can track a series of events like "Registered on Page A and moved to Page B, then an error occurred."

2. Understanding the Logs (Color Coding)

The chronological logs in the right panel are color-coded by information type.

📘 Evidence Stamp ユーザーガイド

バグ報告やシステム調査に必要な「証拠」を一発で保全するツールです。
ドライブレコーダーのように、あなたの操作とブラウザの裏側の動きを常に記録し続けます。

1. 基本的な使い方

  1. 不具合が発生している画面を開きます。
  2. ショートカットキー Ctrl + Shift + E (Macは Cmd+Shift+E) を押します。
  3. 解析画面が開くので、内容を確認して保存・コピーしてください。
💡 ログはリセットされません:
このツールは、ページをリロードしたり、同じサイト内の別ページに移動しても記録を継続します。
「Aページで登録してBページに遷移したらエラーが出た」という一連の流れを追うことができます。

2. ログの見方（色分け）

右パネルの時系列ログは、情報の種類によって色分けされています。

Color Type Description
■ Light Blue (Action) User Actions History of your actions like "Clicked a button" or "Entered text".
Used to verify reproduction steps.
■ Orange (Network) Network Errors Recorded when API calls fail (e.g., 404, 500 errors).
Major causes of system issues.
■ Red (Error) System Errors JavaScript program errors. Crucial clues for developers to fix bugs.
色 種類 説明
■ 水色 (Action) ユーザー操作 「ボタンをクリックした」「文字を入力した」というあなたの操作履歴です。
再現手順を確認するのに使います。
■ 橙色 (Network) 通信エラー API通信に失敗した場合（404, 500エラーなど）に記録されます。
システム不具合の主要な原因です。
■ 赤色 (Error) システムエラー JavaScriptのプログラムエラーです。開発者にとって最も重要な修正の手掛かりになります。

3. Frequently Asked Questions

Q. How do I reset the logs?

Currently, logs are kept until the browser tab is closed. To reset completely and start fresh, please close the tab and reopen it.

Q. What is the preview button for?

It displays the generated image in a large view in a new tab. Useful when logs are long and hard to read on a small screen, or for detailed checks.

3. よくある質問

Q. ログをリセットしたい場合は？

現在、ログはブラウザのタブを閉じるまで保持されます。
完全にリセットして新しく記録を始めたい場合は、一度タブを閉じて、新しいタブで開き直してください。

Q. プレビューボタンは何に使うの？

生成された画像を、新しいタブで大きく表示します。
ログが長くて小さな画面では読みづらい時や、詳細なチェックを行いたい時に便利です。
